# HR-Employee-Analytics

End-to-end HR Employee Analytics project using Python, SQL, and Power BI to analyze employee attrition and identify factors affecting employee turnover.

##  Project Overview

This project analyzes HR employee data using Python, SQL, and Power BI to generate meaningful insights into employee attrition, salary, departments, demographics, overtime, job satisfaction, and work-life balance.

##  Objectives

- Analyze employee attrition patterns
- Identify factors affecting employee turnover
- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Answer HR business questions using SQL
- Build an interactive Power BI dashboard
- Generate actionable business insights

## 🛠️ Tools & Technologies

- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** MySQL, MySQL Workbench
- **Power BI:** Power Query, DAX, Data Modeling
- **Excel:** Data handling and analysis

##  Python Analysis

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Employee and department analysis
- Salary and age analysis
- Attrition and overtime analysis
- Job satisfaction analysis
- Work-life balance analysis
- Data visualization
- Business insights generation

##  SQL Analysis

Used SQL to answer 25 HR business questions, including:

- Total employees and employees who left
- Attrition count and percentage
- Department and gender analysis
- Job role distribution
- Salary and income analysis
- Attrition by department
- Attrition by age group
- Attrition by overtime
- Job satisfaction and work-life balance
- Years at company
- Distance from home
- Employee experience and other HR insights

##  Power BI Dashboard

Created an interactive HR Employee Attrition Dashboard with:

- Total Employees
- Employees Left
- Attrition Rate
- Average Salary
- Average Age
- Average Years at Company
- Department-wise Attrition
- Attrition by Age Group
- Attrition by Overtime
- Average Salary by Education
- Work-Life Balance
- Department, Gender & Job Role filters

##  Key Insights

- Employee attrition was approximately **16%**.
- Sales showed higher employee attrition.
- Employees working overtime had higher turnover.
- Younger employees showed higher attrition.
- Job satisfaction and work-life balance were associated with employee retention.
- Salary, department, job role, overtime, and experience were analyzed as potential attrition factors.
