# HR Employee Attrition Dashboard using Power BI

This project presents an interactive HR Employee Attrition Dashboard developed using Microsoft Power BI. The dashboard analyzes employee demographics, attrition patterns, salary, overtime, department, education, and work-life balance to identify key factors associated with employee turnover.

The goal of this project is to transform raw HR data into an interactive business intelligence dashboard that provides clear and actionable insights for HR decision-making.

 # Project Objectives
Analyze employee attrition patterns
Identify departments with higher employee turnover
Analyze employee demographics
Compare attrition across age groups
Analyze the relationship between overtime and attrition
Compare average salary across education levels
Analyze work-life balance and employee attrition
Create an interactive HR dashboard
Provide data-driven insights for employee retention

#  Key Insights
Employee attrition was approximately 16% of the analyzed workforce.
The Sales department had a higher attrition rate compared with Research & Development.
Employees working overtime showed higher employee turnover.
The 25–35 age group represented the largest group among employees who left.
Work-life balance showed a noticeable relationship with employee attrition.
Average salary varied across different education levels.
Job role, department, overtime, and employee demographics can provide useful indicators for understanding employee turnover.
